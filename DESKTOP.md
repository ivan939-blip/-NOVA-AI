# NOVA AI для Windows

NOVA AI можна встановити як PWA у браузері або зібрати як переносний Windows-застосунок без платних сервісів.

## Локальний запуск

```powershell
npm ci
npm run desktop:dev
```

Застосунок відкриває виробничий NOVA AI у захищеному Electron-вікні. Для роботи потрібен інтернет; авторизація та бібліотека залишаються у звичайному обліковому записі користувача.

## Створення portable `.exe`

```powershell
npm run desktop:pack
```

Зібраний файл з'являється у папці `release`. Також у GitHub Actions доступний ручний workflow **Build NOVA AI Windows app**, який перевіряє тести, збірку й публікує `.exe` як артефакт.

Portable-версія не має платного цифрового підпису Windows, тому під час першого запуску SmartScreen може показати стандартне попередження про невідомого видавця.
